# Raw user stories — angle 2: non-addon guildies & social dynamics

Generated 2026-08-13 (night design run), Sonnet subagent. Consolidation lives in USER-STORIES.md.

1. **[Guildie without addon]** / sees an Announce line with addon-only syntax (`/w`, `/bet`) they can't use / expects a one-line joke, not an instruction manual / annoyed if it reads like being told to install software mid-raid.

2. **[Guild master]** / betting lived in hidden comms for weeks, then a resolve Announce lands with a big pot / expects to feel "in the loop" about guild culture / annoyed if the first they hear of it sounds like real money secretly changing hands guild-wide.

3. **[Officer worried about gambling culture]** / reads "X won 1200g off Y guildies!" / expects friendly-meme framing, not casino framing / annoyed by gambling verbs (wager, odds, jackpot, house) and big pot numbers in public chat.

4. **[Broke new member]** / whispered "wanna get in, it's only 300g" in week one / expects inclusion to be optional and low-pressure / drama if Announce publicly lists who's "in" (implying who's out or too poor).

5. **[Curious onlooker]** / sees a funny Announce and wants the addon / expects a visible next step / annoyed if the line is a dead end (no name, no install pointer that works on Warmane).

6. **[Non-guild friend in raid]** / sees a SoTBookie line in raid chat / expects it self-explanatory and harmless / annoyed if it assumes guild context or fires during a tense moment before callouts.

7. **[Player who loses 300g]** / thought it was a jokey guess / expects losing to feel like a punchline, not a financial hit / salty if "Salty pays Wydlica 300g" gets mockingly repeated in chat for weeks.

8. **[Chat comedian]** / screenshots a funny resolve line to Discord / expects quotable lines / opportunity: punchy templates = free guild morale content; risk if it exposes someone's losing streak as "content."

9. **[Bank alt player]** / settles via bank alt / expects the addon not to care (manual trade) / mild friction if names in the plan force whisper clarification; Announce must never assume gold location.

10. **[Officer]** / sees lifetime net-gold stats tab / expects it private, in-addon / drama if "biggest loser this month" screenshots become public shaming dressed as banter.

11. **[Guildie without addon]** / 4 Announce lines this week for petty bets / expects announces rare enough to stay novel / annoyed by frequency creep — consider a soft "you've announced 3× today, sure?" nudge or trust authors.

12. **[Curious onlooker asking "how do I get this?"]** / expects a guild-standard answer (Discord #addons pinned ZIP) / annoyed if the answer is "ask Wydlica for a personal zip" — announcing something nobody can install becomes its own joke.

13. **[Guild master]** / worried a loser quietly resents a winner / expects a social safety valve / annoyed if there's zero graceful debt-forgiveness gesture when a bet caused real friction.

14. **[Player who loses 300g in a big pot]** / resolve announce says "Y and Z split 900g!" / expects losing to be private if they want / annoyed if resolve announcements can't avoid naming losers — winners-only framing is much lower-drama.

15. **[New member]** / veterans discuss "who's still owed from the Sindragosa bet" in chat days later / expects debts to resolve fast or fade / slow-burn risk: lingering unsettled checkboxes become a "you still owe me" bit that sensitive members read as real tension.

16. **[Chat comedian]** / creates "I bet Steve dies to fire again" — a bet about a non-consenting third party / expects it allowed (it's the core appeal) / **highest drama vector**: Steve finds out via Announce broadcasting a bet about his skill; free-text statement has no consent check.

17. **[Guildie without addon]** / only ever sees "X won 900g!" with zero context / expects a coherent story if anything is public / annoyed if SoTBookie's public face is random gloating.

18. **[Officer / server optics]** / "gold gambling" phrasing seen in guild chat / expects public footprint defensible as meme/social / opportunity: play-money language (pot, tab, dare, "called it"), never bet/wager/odds/gambling in public strings.

19. **[Non-guild friend]** / sees the same rigid template every time / expects variety / annoyed if it reads like bot spam — rotate 2-3 flavor templates.

20. **[Guild master]** / wants public chatter to help guild vibes / opportunity: distinctive consistent voice/branding turns SoTBookie into a guild meme generator outsiders ask about.

21. **[Curious onlooker installing]** / told "drop folder into AddOns" / expects it to just work / real funnel: guild-owned distribution point (pinned Discord ZIP) needed before liberal announcing; otherwise conversion is ~zero.

22. **[Player on a losing streak]** / private stats become gossip fodder / expects streaks not to define reputation / drama if officers use SoTBookie stats as proxy for judgment/poverty in loot-council banter.

## Top 5 design risks/opportunities from this angle

1. **Risk — betting on a non-consenting third party** (16). Highest drama potential; needs an explicit design decision (nudge, or accept as guild-banter risk). Flagged, not solved.
2. **Risk — Announce frequency fatigue** (11, 17, 19). Soft convention: announce only open+resolve, never lock/cancel, one line per event.
3. **Risk — public loser-naming turns banter into shaming** (7, 14, 22). Announce format centers winners + pot; loser names stay inside the addon UI.
4. **Risk — install funnel is a dead end on Warmane** (5, 12, 21). Needs a guild-owned ZIP distribution point (pinned Discord) before Announce is used liberally.
5. **Opportunity — deliberate funny non-gambling-coded voice** (18, 20). Cheap string templates, high morale payoff, keeps officer/GM comfort.

### Recommended Announce formats (rotate, one line, no slash-syntax)

- Open: `SoTBookie: Wydlica is calling it — "we wipe next pull." Anyone want a piece of that?`
- Resolve: `SoTBookie: Called it! Wydlica cleans up on the "we wipe next pull" tab.`
- Resolve alt: `SoTBookie: The "next pull" tab is settled — turns out Wydlica was right. Rough night for the doubters.`
